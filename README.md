♟️ Космическая шахматная арена (3D Sci-Fi Chess)
Интерактивная 3D-шахматная сцена с элементами научной фантастики, созданная с использованием Three.js. Проект представляет собой визуально насыщенную арену с возможностью выбора фигур, переключения режимов камеры и выбора сложности ИИ.

🚀 Функционал
🎮 3D-сцена с анимированными звёздами, туманностями, планетами и энергетическими эффектами

🧊 Шахматная доска с детализированными фигурами в стиле «свет/тень»

🖱️ Выбор фигур кликом мыши с визуальной подсветкой

🎥 Режимы камеры:

Free Look — стандартный обзор с параллаксом

Cinematic — автоматическое вращение камеры вокруг арены

⚔️ Режим битвы с автоматическим переключением между фигурами

🤖 Выбор сложности ИИ (легко / средне / сложно) через модальное окно

💡 Энергетические импульсы, пульсация, световые лучи и парящие искры

🛠️ Технологии
Three.js (r160) — рендеринг 3D-сцены

HTML5 / CSS3 — интерфейс и стилизация

JavaScript (ES6) — логика взаимодействия и анимации

🎮 Управление
Действие	Результат
Движение мыши	Параллакс-эффект (наклон арены)
Клик по фигуре	Выбор фигуры с подсветкой
Кнопка «Кино-камера»	Включение/выключение кинематографичного режима
Кнопка «Начать партию»	Открытие модального окна выбора сложности
Выбор сложности	Запуск режима битвы с ИИ выбранного уровня
🤖 Сложности ИИ
Уровень	Описание
🟢 Лёгко	Имитация случайных ходов (демонстрация)
🟡 Средне	Оценка позиции (заглушка для расширения)
🔴 Сложно	Просчёт на 2 хода вперёд (заглушка)
ℹ️ Реализация логики ИИ оставлена для дальнейшего расширения — текущая версия демонстрирует интерфейс и визуальную составляющую.
